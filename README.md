# 项目航图

一个使用 Python 和 PySide6 构建的 Markdown 工作大纲管理器。

项目航图把每个项目的大纲保存为独立的 Markdown 文件：左侧项目库负责收纳和切换项目，中间区域负责编辑，右侧区域负责预览、文档目录、任务面板和项目信息。

## 功能亮点

- 自动识别 `Markdown` 文件夹中的 Markdown 大纲
- 导入外部 Markdown 时记录原文件路径，不复制文件，后续直接访问原地址
- 同名项目会在项目库中附带来源目录显示，删除前会展示完整绝对路径
- 支持新建、删除项目分组，并可通过项目右键菜单调整归属；空分组也会保留
- 编辑、预览、分栏三种视图模式
- Markdown 实时渲染，支持标题、列表、任务、引用、代码、表格、分隔线和图片
- 支持中文右键菜单、查找替换和格式工具栏
- 选中多行后使用 `Tab` / `Shift+Tab` 批量缩进
- 数字编号自动续写，支持标准 Markdown 编号格式
- 图片粘贴后复制到项目内的 `Media` 缓存目录，方便整体迁移
- 双击预览图片可打开独立图片查看器，并使用滚轮缩放
- 编辑栏与预览栏支持独立缩放和自动换行设置
- 左右侧栏支持折叠、展开和状态记忆
- 项目库支持置顶、右键操作和长按拖拽排序，顺序会在下次启动时恢复
- 项目列表选中后可按 `Delete` 删除，并可选择移入备份或永久删除
- 每个项目独立记忆编辑与预览滚动位置，再次打开自动恢复
- 编辑内容采用 750 毫秒防抖自动保存，连续输入期间不会反复写盘
- Python 源码版与 exe 共用单实例机制，重复启动会唤醒已有窗口
- 主窗口、功能子窗口和 Windows 任务栏统一使用项目航图图标
- 保存时保留光标、选区和滚动位置
- 支持浅色与深色主题

## 快速开始

### 直接运行

下载仓库中的 `dist/项目航图.exe`，将它放在项目根目录后直接运行。

也可以双击：

`启动项目航图.bat`

### 从源码运行

```powershell
python -m pip install PySide6 Markdown
python 项目航图.py
```

## 添加自己的项目

把自己的 `.md` 文件放入：

```text
Markdown/
```

重新打开程序后，文件会自动出现在左侧项目库中。

## 目录说明

```text
项目航图/
├── 项目航图.py                 # 兼容启动入口
├── project_map/                # 主程序包
│   ├── config.py               # 路径与运行配置
│   ├── editor.py               # Markdown 编辑器与编号处理
│   ├── project_list.py         # 项目列表拖拽、动画与快捷键
│   ├── single_instance.py      # 单实例检测与已有窗口唤醒
│   ├── preview.py              # Markdown 预览与图片查看器
│   ├── dialogs.py              # 项目属性、命名、查找替换对话框
│   ├── window.py               # 主窗口组装
│   └── mixins/                 # 界面、项目、预览、格式、面板和操作职责
├── 启动项目航图.bat             # Windows 启动脚本
├── dist/项目航图.exe            # 可直接运行的当前版本
├── assets/                      # 程序图标
├── Markdown/项目航图公开演示.md  # 公开演示大纲
├── 项目航图.spec                # PyInstaller 配置
└── README.md                   # 项目说明
```
