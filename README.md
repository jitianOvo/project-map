# 项目航图

一个使用 Python 和 PySide6 构建的 Markdown 工作大纲管理器。

当前版本：v3.5。

项目航图把每个项目的大纲保存为独立的 Markdown 文件：左侧项目库负责收纳和切换项目，中间区域负责编辑，右侧区域负责预览、文档目录、任务面板和项目信息。

## 功能亮点

- 自动识别 `Markdown` 文件夹中的 Markdown 大纲
- 导入外部 Markdown 时记录原文件路径，不复制文件，后续直接访问原地址
- 同名项目会在项目库中附带来源目录显示，删除前会展示完整绝对路径
- 支持新建、删除项目分组，并可通过项目右键菜单调整归属；空分组也会保留
- 项目右键菜单支持直接在资源管理器中打开 Markdown 所在位置
- 编辑、预览、分栏三种视图模式
- Markdown 实时渲染，支持标题、列表、任务、引用、代码、表格、分隔线和图片
- 支持中文右键菜单、查找替换和格式工具栏
- 窄窗口下，工具栏的 `»` 会列出放不下的工具，点击即可执行
- 快速工具栏和格式工具栏均可折叠；设置中可勾选工具、拖动排序，并记忆配置
- 新建或项目属性中可选填关联文件/文件夹，填写后才显示“打开项目位置”入口
- 支持整数轮次与小数子版本标题的增加、减少和后续自动重编号
- 项目和选中文本均可设置红、蓝、绿三档优先级
- 选中多行后使用 `Tab` / `Shift+Tab` 批量缩进
- 数字编号自动续写，支持标准 Markdown 编号格式
- 标准连续编号中按 `Shift+Enter` 插入新项，后面紧邻的编号自动加一
- 图片粘贴后复制到项目内的 `Media` 缓存目录，方便整体迁移
- 图片缓存支持配置多个附加 Media 目录，源码版与编译版可交叉查找图片
- 双击预览图片可打开独立图片查看器，并使用滚轮缩放
- 编辑栏与预览栏支持独立缩放和自动换行设置
- 左右侧栏支持折叠、展开和状态记忆
- 项目库支持置顶、右键操作和长按拖拽排序，顺序会在下次启动时恢复
- 项目列表选中后可按 `Delete` 删除，并可选择移入备份或永久删除
- 每个项目独立记忆编辑与预览滚动位置，再次打开自动恢复
- 编辑内容采用 750 毫秒防抖自动保存，连续输入期间不会反复写盘
- Python 源码版与 exe 共用单实例机制，重复启动会唤醒已有窗口
- 主窗口、功能子窗口和 Windows 任务栏统一使用项目航图图标
- 保存时保留光标、选区和滚动位置
- 支持浅色与深色主题

## 快速开始

### 直接运行

下载仓库中的 `dist/项目航图.exe`，将它放在项目根目录后直接运行。

也可以双击：

`启动项目航图.bat`

### 从源码运行

```powershell
python -m pip install -r requirements.txt
python 项目航图.py
```

## 添加自己的项目

把自己的 `.md` 文件放入：

```text
Markdown/
```

重新打开程序后，文件会自动出现在左侧项目库中。

## v3.5 使用方式

### 调整工具栏

点击任意工具栏右侧的“设置”，切换“快速工具”或“格式工具”页签。勾选表示显示，取消勾选表示隐藏；拖动条目或点击“上移 / 下移”调整顺序，最后点击“保存设置”。原有快捷键不会因隐藏按钮而失效。

点击“快速工具 ▾”或“格式工具 ▾”收起按钮，再点击即可展开。窄窗口中使用右侧 `»` 菜单访问剩余工具。

### 添加版本提示词

在编辑区右键，或在格式工具栏使用：

- “增加 Vn”：跟随光标上方最近的版本标题。例如 `# V1` 后增加 `# V2`，或 `## v3.1` 后增加 `## v3.2`。
- “增加子版本”：在大版本下开始小数轮次。例如 `# V3.5` 下生成 `## v3.1`；已有子版本时继续增加最后一位。
- “减少 Vn”：删除选中的版本标题；未选中标题时删除光标上方最近的一个。标题后的说明和正文不会删除，后续同级编号相应减一。

在 V1 与 V2 之间插入 V2 时，原来的 V2、V3 会顺延为 V3、V4。整数父轮次改变时，带有对应数字前缀的子版本一起调整。子版本的编号不会跨越上级标题或其他版本系列；代码块里的标题不会参加扫描。每次操作都可使用 `Ctrl+Z` 整体撤销。

非空行上执行增加时，标题插在该行后面；空行上执行时，标题插在当前行，然后光标进入标题下方空行。

### 设置优先级与项目位置

项目库右键“项目优先级”可标记最紧急（红）、优先（蓝）、普通（绿），列表显示对应色点。编辑区右键“优先级”可给选中文字或当前行着色；格式工具栏提供相同操作和清除入口。文本优先级使用 Markdown 支持的 HTML `span` 保存，预览中也会显示颜色。

新建时可以选填“项目位置”，之后也可在项目属性中修改。未填写时不显示“打开项目位置”；文件夹会直接打开，文件会在资源管理器中定位。该位置与大纲的 Markdown 保存路径相互独立。

### 在编号中间插入需求

例如光标位于 `2. 第二项` 行末，按 `Shift+Enter`：

```markdown
1. 第一项
2. 第二项
3. 新需求在这里输入
4. 原来的第三项
```

仅“数字 + 点 + 空格/制表符”的标准编号生效；空白行、不同缩进、非连续数字会结束重编号。普通回车仍按原逻辑续写，非标准的 `2.第二项` 不会触发插入重编号。

## 开发与测试

需要 Python 3.11 或更新版本。在项目根目录运行：

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
pwsh -NoLogo -NoProfile -NonInteractive -File scripts/build.ps1
pwsh -NoLogo -NoProfile -NonInteractive -File tests/smoke_frozen.ps1
```

测试使用临时项目和离屏窗口，不会改动已有大纲。构建脚本会临时隔离 DLL 搜索路径，避免其他工具的旧运行库混入；构建结果仍为 `dist/项目航图.exe`，原启动脚本与程序文件名保持不变。

## 目录说明

```text
项目航图/
├── 项目航图.py                 # 兼容启动入口
├── project_map/                # 主程序包
│   ├── config.py               # 路径与运行配置
│   ├── editor.py               # Markdown 编辑器与编号处理
│   ├── editor_workflow.py      # 版本操作、优先级与插入编号
│   ├── versioning.py           # 无界面的版本扫描与重编号规则
│   ├── toolbars.py             # 自适应工具栏和设置对话框
│   ├── menus.py                # 无原生黑边的透明圆角弹出菜单
│   ├── project_list.py         # 项目列表拖拽、动画与快捷键
│   ├── single_instance.py      # 单实例检测与已有窗口唤醒
│   ├── preview.py              # Markdown 预览与图片查看器
│   ├── dialogs.py              # 项目属性、命名、查找替换对话框
│   ├── window.py               # 主窗口组装
│   └── mixins/                 # 界面、项目、预览、格式、面板和操作职责
│       └── media.py            # 默认与附加图片缓存目录管理
├── 启动项目航图.bat             # Windows 启动脚本
├── dist/项目航图.exe            # 可直接运行的当前版本
├── assets/                      # 程序图标
├── Markdown/项目航图公开演示.md  # 公开演示大纲
├── 项目航图.spec                # PyInstaller 配置
├── requirements.txt            # 源码运行依赖
├── requirements-dev.txt        # 打包依赖
├── tests/                      # 编辑器与界面回归测试
└── README.md                   # 项目说明
```
