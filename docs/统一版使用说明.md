# 项目航图统一版

Windows 只保留原来熟悉的编辑器，云同步是其中的附加功能。

## 现在的数据位置

| 内容 | 默认位置 |
|---|---|
| 项目大纲 | 项目外层 `Markdown` |
| 图片缓存 | 项目外层 `Media` |
| 配置、项目属性、同步状态 | 项目外层 `Data` |
| 本地备份与迁移记录 | 项目外层 `Backups` |

源码运行与 `dist/项目航图.exe` 使用同一份资料和配置。`dist` 内旧数据目录是指向外层的兼容链接，不是另一份副本。旧的 Windows 云端入口也会打开统一程序，并共享单实例检测。

这次合并了内层 18 份与外层 7 份 Markdown，合计 25 份；图片合计 13 张，没有文件内容冲突。内层项目属性优先，原先链接到外层的 5 个项目已转换为同一项目库中的本地项目，不重复显示。独立 Windows 云端缓存经导出核对，没有大纲或图片需要额外合并。

原始大纲、图片、配置和旧程序都在 `Backups/整合迁移-20261006` 中保留。迁移前后正文与图片按 SHA-256 校验，不改写正文。不要把迁移备份当成日常数据源。

## 手动换数据源

打开右上角“设置”→“数据目录”，选择 Markdown 和图片缓存两个文件夹，保存后立即生效。可随时恢复“项目外层目录”，也可以切回先前的文件夹。每个大纲文件夹的项目属性与阅读进度分别保留，切换不会搬走或删除原文件。

需要打开其他项目文件时，原来的“导入”功能依然记录外部路径；缓存目录中还有多个旧 Media 时，用“图片缓存”添加附加查找位置。

## 连接云端

1. 点击“云同步”，或“设置”→“云同步”。
2. 保留现有服务器地址，填写云账号和密码，点击“登录并启用”。首次登录信息可从该页面的按钮打开。
3. 手机登录同一账户。电脑当前 Markdown 文件夹中的大纲会出现在手机；图片一起同步。
4. 外部链接项目默认不上传，需要时勾选对应选项。

本机仍实时自动保存，云连接失败不会阻止编辑。暂停同步或退出账号不会清空本地文件，也不会删除云端项目。没有自动把本机私人资料上传到服务器或公开仓库。

同时修改不同位置可自动合并；同一位置冲突保留副本。同步请求发出后继续输入的内容会重新合并，不被旧响应覆盖。远端删除本地大纲前先写入 `Backups/Cloud`。窗口布局、主题、光标与进度条属于本机，不被手机配置覆盖。

## 验证方式

```powershell
python -m unittest discover -s tests -p 'test_*.py' -v
pwsh -NoLogo -NoProfile -NonInteractive -File tests/smoke_frozen.ps1
```

跨端测试需要同级云服务源码和本机 Playwright；它使用临时服务器与公开测试大纲，不接触现有项目内容。已验证本地编辑器→手机界面的正文与图片、手机→本地文件、断网修改后合并、冲突保留、目录切换、光标与预览滚动保持，以及单文件版初始化与重复启动。

真实安卓设备仍未通过 ADB 连接、安装或操作。

最终回归结果：61 项原桌面与整合测试、15 项云服务/网页测试、6 项编辑规则测试通过，共 82 项。单文件程序的正文、图片云同步，以及旧云端入口转到同一程序，都已用隔离数据验证。
