# 云端大纲编辑交接（4.2.1）

同一份云端大纲只允许一个客户端编辑；不同大纲可同时工作。电脑和手机都要更新到支持占用的版本。

## 日常使用

1. 点击大纲，程序先同步、申请服务器占用、拉取最新版，再允许输入。
2. 对方正在编辑时，会提示具体是电脑端还是手机端。等待端约每 2 秒自动确认；释放后自动取得占用并加载最新正文，无需重新点击。
3. 切换大纲前，当前正文先保存到本机并确认上传成功，再释放旧占用。新大纲被占用时，旧大纲仍可继续编辑。
4. 点击“结束本端编辑”即可主动交接。电脑正常关闭、最小化和手机进入后台也会交接；回来后自动确认占用。也可手动点击“继续编辑”。

后台同步仍可以读取更新，但主动结束后不会自动抢回编辑占用。阅读进度、缩放等本机设置仍分别保留。

## 断网或异常退出

- 每 5 秒续期一次，服务器占用 20 秒失效；客户端提前 5 秒停止编辑，计时从请求发出时开始，避免慢响应使客户端误以为占用仍有效。
- 检测到续期失败或断网时暂停编辑，已经输入的草稿仍保存到本机；不删除正文，也不直接拿旧稿覆盖云端。
- 正常切换时先同步当前正文；主动结束、关闭窗口或进入后台时，即使最后一次同步失败，也会保留本地草稿并尝试释放占用，不再通过心跳无限续期。恢复联网后重新同步；程序闪退或系统结束进程时，另一端最多等待约 20 秒。
- 不提供强抢按钮。原有合并和冲突副本仍保留，处理历史离线稿、延迟响应或旧客户端留下的修改。

未成功上云的本地文件，以及明确暂停同步后的本地模式，不属于互斥编辑范围；不得把两端断网继续编辑描述为无冲突协作。

## 实现与验证入口

服务器以大纲 ID 为唯一键原子授予短期占用。身份来自实际登录会话，不信任请求自报设备名称。单实例电脑程序、安卓应用保留本安装的客户端 ID，重开时可恢复自己的占用；浏览器不同窗口保持独立。恢复会话时更换凭证，旧窗口迟到的续期、释放不能影响新会话。续期、释放、写入都校验对应凭证，过期旧客户端不能释放新端占用或覆盖新版本。
