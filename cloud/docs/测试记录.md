# 云端预览版测试记录

本轮日期：2026-10-06。测试只使用人工构造的公开内容，不读取私人项目大纲。

## 已验证

- Python：11 项服务端测试，覆盖三方合并、冲突保留、元数据合并、删除与编辑冲突、同名项目独立、重试幂等、超大合并安全退回副本、非法字段、认证、图片哈希与路径保护。
- JavaScript：6 项规则测试，覆盖格式取消、标题等级替换、编号续写与插入重排、Tab / Shift+Tab、版本插入删除、同步返回期间保留最新输入。
- 浏览器：4 项端到端测试，覆盖桌面与手机宽度、回车新建、预览滚动不重置、图片渲染与整体缩放、断网编辑与重新打开、两端自动合并与冲突副本、查找替换、HTML 清洗。
- Qt 源码版：离屏启动检查，确认共享界面、保存函数和原生桥正常加载。
- Windows 打包版：使用 `--self-test` 离屏启动，确认共享界面、原生桥和窗口图标加载；另外通过原生网络桥实际完成线上登录、同步、退出登录和正常关闭，项目数仍为 0。运行库问题固定在构建脚本中，不修改系统文件。
- Android：Java 编译、资源链接、Dex 生成、APK 对齐和 v2 / v3 签名校验；检查清单确认应用图标、启动 Activity、Android 8.0 最低版本和 INTERNET 权限。
- 线上：HTTPS 页面与健康接口，未登录访问返回 401，应用账户登录与退出、下载 APK 与本地 SHA-256 一致。线上工作区初始项目数为 0。

自动化脚本在 `tests/`，线上验证结果在 `.state/live-verification.json`。安装包哈希和构建资源一致性由 `scripts/release_manifest.py` 生成到 `dist/发布校验.json`。

## 尚未验证

没有运行任何 ADB 命令，没有连接或安装到手机。真机的微信语音输入、不同系统剪贴板图片、相册文件选择、应用退到后台后被系统回收、不同 WebView 版本的手势和键盘行为，需获得授权后实测。

本轮是个人云端首版，不宣称已经完整复刻旧版所有 Windows 专属行为，也不是 Google Play 上架版。旧 Windows 项目和桌面快捷方式保持不变。
